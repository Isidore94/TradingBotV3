How to write a test that can fail:
- One test per item, named for the behaviour. Put them in `tests/test_<slug>_*.py`.

  half-day session has 39 bars.
- Assert the number, not the shape. Never `or True`, never a literal `vocab_version`, never
  a window in calendar days, never a fixture generated by the code under test.
